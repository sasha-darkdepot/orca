Data Flow

How sessions are fetched
~/.claude/projects/
{encoded-worktree-path}/*.jsonl
→
ClaudeSessionProvider
fs.readdir + parse first user msg
~/.codex/state_5.sqlite
WHERE cwd LIKE '{path}%'
→
CodexSessionProvider
shell: sqlite3 -json
~/.local/share/opencode/
opencode.db
→
OpenCodeSessionProvider
shell: sqlite3 -json
↓ all merge into ↓
getRecentSessions(worktreePath, limit)
sorted by lastActiveAt, deduped

Key Constraint

Worktree ↔ Session matching
Each worktree has a path on disk. Session providers filter by this path.
Claude: ~/.claude/projects/{path.replace(/\//g, '-')}/
Codex/OpenCode: WHERE cwd LIKE '{worktree.path}%'
Landing (global): no path filter — show all sessions across all worktrees.
